# Скриншоты для инструкции `/crm/help`

Страница инструкции ([app/crm/help/page.jsx](../app/crm/help/page.jsx)) показывает вместо
каждого скриншота рамку-заглушку с подписью «что снять». Как только файл появляется в
`public/help/`, картинка подставляется сама — править код не нужно.

Формат: PNG, ширина 1400–1800 px (окно браузера ~1440 px, масштаб 100 %). Персональные
данные реальных клиентов лучше замазать.

| Файл | Что снять |
| --- | --- |
| `login.png` | Страница `/authorize` с полями «Адрес электронной почты» и «Пароль» |
| `shell.png` | Главная с раскрытым (наведённым) боковым меню: видны все разделы и счётчик задач |
| `dashboard.png` | Дашборд целиком: плитки, «Мои задачи», сделки по статусам, лента активности |
| `leads.png` | Таблица заявок с сайта с видимыми кнопками действий в строке |
| `counterparty-new.png` | Форма нового контрагента с раскрытыми подсказками поиска по ИНН/названию |
| `counterparty-card.png` | Карточка контрагента целиком: шапка с кнопкой смены типа, дерево «Проекты и сделки», реквизиты, группа компаний, панель активности |
| `counterparty-type-switch.png` | Карточка с открытым окном «Смена типа контрагента»: список связей и кнопка «Сменить тип» |
| `contacts.png` | Справочник контактов с открытой формой добавления |
| `projects-kanban.png` | Канбан проектов с карточками в колонках, видны вкладки и фильтры |
| `project-duplicate.png` | Форма проекта в момент предупреждения о дубле + поле комментария |
| `deals-kanban.png` | Доска сделок с заполненными колонками и панелью фильтров |
| `deal-card.png` | Карточка сделки: шапка со статусом и «Сформировать КП», стороны, позиции, активность |
| `deal-auction.png` | Аукционная сделка с открытой вкладкой «Параметры аукциона» |
| `proposal.png` | Страница КП: раскрытые «Параметры КП» и сам документ с итогами |
| `shipment-form.png` | Открытая форма новой отгрузки с подставленными позициями и получателем |
| `shipments-list.png` | Раздел «Отгрузки» со строками в разных статусах (желательно с просрочкой) |
| `tasks-kanban.png` | Доска задач с карточками в «Просроченные», «На сегодня», «На завтра» |
| `task-close.png` | Модальное окно закрытия задачи с выбором статуса и комментарием |
| `products.png` | Список товаров с остатками и кнопкой «Обновить остатки» |
| `supply.png` | Отчёт «Обеспечение»: плитки и таблица баланса, желательно с дефицитной строкой |
| `discount.png` | Форма сделки/проекта, где под полем «Скидка, %» видна подпись источника |
| `profile.png` | Страница профиля с блоками «Личные данные» и «Доступ» |

Тексты подписей живут рядом с самим разделом — в
[components/crm/help/sections.jsx](../components/crm/help/sections.jsx), поле `shoot`
у компонента `HelpShot`.
