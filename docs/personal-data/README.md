# Документы по персональным данным

Черновики внутренних документов ООО «ПК „НЕОМЕД“». Составлены под фактическую
обработку данных в проекте: форма обратной связи на сайте, CRM, кадровый учёт.
Перед подписанием их должен вычитать юрист.

Публикуется только Политика. Остальное хранится в компании и предъявляется по
запросу Роскомнадзора.

## Порядок действий

1. Заполнить плейсхолдеры `{{...}}` во всех документах и в Политике.
2. Отдать комплект юристу на вычитку.
3. Издать приказ о назначении ответственного.
4. Издать приказ об утверждении Политики и Положения, подшить их как приложения.
5. Ознакомить работников под подпись.
6. Опубликовать Политику на сайте, проставив в ней дату утверждения.
7. Подать уведомление в Роскомнадзор, беря сведения из перечня ИСПДн.
8. Определить уровень защищённости ИСПДн актом (с профильным специалистом).

Пункты 6 и 7 делаются после 4: в уведомлении и в опубликованной политике данные
должны совпадать — расхождения между ними как раз то, за что цепляются при
проверке.

## Чего в комплекте нет

Формы, которые понадобятся при обычной работе, но которые проще завести по
факту первой необходимости: акт об уничтожении персональных данных, журнал
учёта обращений субъектов, перечень должностей с доступом к персональным
данным, форма согласия кандидата, акт внутреннего контроля. Все они упомянуты
как приложения в Положении.

Также не входит техническая часть — модель угроз и акт определения уровня
защищённости. Их готовят вместе со специалистом по защите информации, шаблоном
тут не обойтись.
